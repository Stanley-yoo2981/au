# 호주 교민 한국 법률문제 랜딩페이지

법무법인 여온 — 호주 거주 한인이 한국에 두고 온 법률문제 랜딩페이지.

다루는 분야는 네 갈래다. **상속 / 자녀 병역·국적 / 무역·거래 대금 / 한국 부동산**.
상속 전용으로 시작했다가, 실제 수임 사건이 상속에 국한되지 않고
하단 요약(관할 선택·보전처분·집행)도 국제 분쟁 일반이라 범위를 넓혔다.

단일 페이지에 분야별 섹션을 두는 구조다. 분야별 전용 페이지로 쪼개는 안도 검토했으나
관리 부담과 광고 운영 단순성을 이유로 단일 페이지로 정했다.
다만 분야마다 타겟 연령이 다르므로(상속 50~60대 / 자녀 병역 40~50대 학부모),
페이스북 광고 문구를 분야별로 나눌 경우 랜딩과 어긋나지 않는지 확인이 필요하다.

## 섹션 순서

```
히어로 → 01 협약 → 현장 → 02 변호사 → 03 절차 → 04 기한
       → 05 분야 → 06 사례 → 07 질문 → 08 상담
```

변호사와 절차를 앞으로 올렸다. 하단에 있으면 읽히지 않는다.
"연락을 주시면 이렇게 진행됩니다" 3단계는 08 상담의 폼 바로 위에 둔다.
아직 연락할 마음이 없을 때 읽히면 소용이 없다.

## 파일

```
index.html          랜딩 본체. 단일 파일, 외부 요청 0, 자바스크립트 라이브러리 0
images/
  au-seminar.webp          히어로. 2025년 2월 시드니 설명회
  au-seminar-2.webp        현장 섹션. 청중이 보이는 컷
  au-seminar-3.webp        미사용. 예비
  mou-korean-association.webp    호주시드니한인회 협약식
  mou-chamber-of-commerce.webp   호주한인상공회의소 협약식
  mou-welfare-society.webp       호주한인복지회 협약식
  lawyer-yoo-younggyu.webp       유영규 대표변호사
  lawyer-kim-hwanseop.webp       김환섭 변호사
  lawyer-hong-giwoong.webp       홍기웅 변호사
  lawyer-kim-seonho.webp         김선호 변호사
  src/                     WebP 재변환용 원본(jpg·png). 배포에는 쓰지 않는다
```

페이지 총 전송량 약 760KB. 표시에 쓰는 이미지는 전부 WebP다.
원본(4032px, 장당 2~3MB)을 그대로 넣으면 11MB가 되어 호주에서 모바일 로딩이 무너진다.

변호사 사진 네 장은 440x513 으로 비율을 맞춰 두었다. 한 장만 비율이 다르면
object-fit cover 로 채우는 과정에서 그 사람만 얼굴이 크게 나온다.
김선호 변호사 사진은 사진관 웹페이지에서 받은 파일이라 하단에 사진관 소개문이
찍혀 있었고, 그 부분을 잘라낸 상태다. 원본 납품본으로 교체하는 것이 맞다.

## 유입 경로

검색이 아니라 **페이스북·유튜브** 기준으로 설계했다.
키워드 플래너상 `재외국민 상속` `해외 상속` `입국 없이 상속` `한국 재산 상속` 모두 검색량 0이라
검색광고로는 이 대상에 도달할 수 없다.

그래서 구조가 기존 랜딩과 다르다.

- 니즈를 자각하지 못한 상태로 유입되므로 히어로에서 네 분야를 먼저 호명한다
- 소셜 유입은 의심하며 들어오므로 **협약 섹션(01)을 최상단**에 둔다
- 국제전화는 장벽이라 **카카오톡을 1순위 CTA**로 둔다 (계정 데이터상 카톡이 전 접촉의 34%)
- 폼은 3필드 상한 (성함 / 연락처 / 카카오톡 ID)

## 발행

이 저장소는 소스 보관용이다. 실제 공개는 다른 운영 랜딩과 마찬가지로
`yeoon.co.kr` 아래에 올라가야 한다. 홈페이지 담당자에게는 `index.html` 과 `images/` 의 **webp 파일만** 넘긴다.
`images/src/` 는 재변환용 원본이라 넘길 필요가 없다.

## 사례 섹션 작성 원칙

06 사례 섹션은 아래 기준으로 다듬었다. 문구를 수정할 때도 유지할 것.

- **진행 중인 사건과 종결된 사건을 반드시 구분한다.** 카드 상단에 `진행 중` / `종결`
  배지를 단다. 진행 중인 사건의 파란 박스는 `결과` 가 아니라 `현재` 로 표기하고,
  경과만 쓴다. 결과를 암시하는 문장을 넣지 마라.
  - 현재 상태 — 사례 1(호주 상속 예금) 진행 중 / 사례 2(호주 무역 대금) 진행 중 /
    사례 3(캐나다 상속포기) 종결
  - 사건이 종결되면 배지와 박스 라벨을 함께 바꿔야 한다. 한쪽만 바꾸면 어긋난다.
- **완료된 사건은 과거형으로만 쓴다.** 현재형("돌파합니다")은 향후 결과 약속이 되어
  광고 규정상 문제가 된다.
- **승소·패소 표현을 사건 성격에 맞게 쓴다.** 상속포기는 비송사건이므로 승소가 아니라
  심판 수리다.
- **우월성 표현을 쓰지 않는다.** `압도적` `완벽한` `최고` 등은 객관적 근거를 댈 수 없다.
- **상대방을 비하하지 않는다.**
- 사례 하단 면책 문구는 지우지 마라.

## 다루지 않기로 한 것

아래 두 가지는 첫 방문자 인상을 점검하면서 약점으로 짚었으나, 넣지 않기로 했다.
다시 논의할 때 같은 이야기를 반복하지 않도록 남겨 둔다.

- **변호사 4인의 기수·연차** — 젊어 보인다는 인상에 대한 직접적인 답이지만 넣지 않는다.
  대신 02 변호사 섹션에서 분야를 나누지 않고 네 사람이 같은 사건을 함께 본다는
  검토 구조로 답하고 있다.
- **호주 종결 사례** — 현재 종결 건은 캐나다 건 하나다.
  사례 순서를 종결 건부터 두고, 진행 중 배지를 상태(진행 중)가 아니라
  수행 내용(소송 진행 중 / 보전 절차 진행 중)으로 적어 보완했다.

## 남은 작업

- 진행 중 사건(사례 1·2)의 경과 서술이 현재 상태와 맞는지 정기 확인. 종결 시 배지 교체
- 진행 중인 수임 사건을 광고에 게재하는 것이 규정상 가능한지 변호사 확인 (E-2)
- 유튜브 영상 기획 — 랜딩만으로는 유입이 생기지 않는다
- MOU 3개 단체 로고 사용 시 각 단체 동의 확인

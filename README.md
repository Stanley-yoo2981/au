# 호주 교민 상속 랜딩페이지

법무법인 여온 — 호주 거주 한인 대상 한국 상속 랜딩페이지.

## 파일

```
index.html          랜딩 본체 (단일 파일, 외부 의존 없음)
images/
  au-seminar.jpg        히어로. 호주 현지 세미나 (1600×900)
  au-seminar-2.jpg      미사용. 예비
  au-seminar-3.jpg      미사용. 예비
  mou-korean-association.jpg    호주 시드니한인회 협약식
  mou-chamber-of-commerce.jpg   호주한인상공회의소 협약식
  mou-welfare-society.jpg       호주한인복지회 협약식
  lawyer-yoo.png        유영규 대표변호사
```

페이지 총 전송량 약 900KB. 모든 이미지는 1600px 이하 / 장당 270KB 이하로 압축된 상태다.
원본(4032px, 장당 2~3MB)을 그대로 넣으면 11MB가 되어 호주에서 모바일 로딩이 무너진다.

## 유입 경로

검색이 아니라 **페이스북·유튜브** 기준으로 설계했다.
키워드 플래너상 `재외국민 상속` `해외 상속` `입국 없이 상속` `한국 재산 상속` 모두 검색량 0이라
검색광고로는 이 대상에 도달할 수 없다.

그래서 구조가 기존 랜딩과 다르다.

- 니즈를 자각하지 못한 상태로 유입되므로 **문제 인식 섹션(3번)** 이 앞에 붙는다
- 소셜 유입은 의심하며 들어오므로 **MOU 신뢰바를 최상단**에 둔다
- 국제전화는 장벽이라 **카카오톡을 1순위 CTA**로 둔다 (계정 데이터상 카톡이 전 접촉의 34%)
- 폼은 3필드 상한 (성함 / 연락처 / 카카오톡 ID)

## 변호사 검토 대기 항목

법률 기재사항 중 확정되지 않은 문장은 `index.html` 안에 HTML 주석으로 표시해 두었다.
검토 전에는 공개하지 마라.

| A-2 | 4번 기한 | 상속세 9개월 적용 요건 (`피상속인 또는 상속인 전원` 여부) |
| A-3 | 4번 기한 | 유류분 1년 기산점 · 10년 제척기간 병기 여부 |
